Osvauld is building **Xnet—the extended internet**: a private and programmable environment for shared software. Instead of depending on a platform's accounts, database, APIs, and application server, a workspace carries its own identity, data, application code, and authority.

The current implementation is **`osvauld2`**. It includes the new desktop runtime, sovereign identities, encrypted local storage, workspaces, sandboxed Lua applications, and CRDT-backed application data. Networking, sovereign-node integration, and signed capability permits are the next major layers and are not presented here as finished features.
