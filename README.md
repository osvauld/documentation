# Osvauld documentation

Public documentation for [Osvauld](https://osvauld.com), Xnet, and the current `osvauld2` runtime.

## Content

- `src/content/docs/xnet/` — product model and direction
- `src/content/docs/runtime/` — current architecture, status, Lua API, identity, storage, and vault

The public documentation must clearly distinguish implemented behavior from planned Xnet layers. The engineering source of truth is the `docs/` directory in the `osvauld2` repository.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
